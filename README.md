# Songcraft

Make your first song without knowing music theory: hum a tune, and Songcraft suggests the chords, beats and notes that fit, with Gemini as your producer and every sound still yours.

Songcraft walks you through a song one layer at a time. You build the beat drum by drum, pick chords with suggestions for what fits your style, hum or build the melody, write your own lyrics with feedback from Gemini, and arrange it all into a song you can download or share with a QR code. None of the audio is generated by AI; the instruments are real recordings playing the notes you chose.

**Live:** https://songmaker-six.vercel.app

## Run locally
```
npm install
npm run dev
```

## Built with
- React, TypeScript, Vite, Vitest, oxlint
- Tone.js and the Web Audio API (instruments, timing, playback and WAV export)
- pitchy (pitch detection for humming)
- Google Gemini on Vertex AI: `gemini-3.1-pro-preview` for song planning; `gemini-3.6-flash` for the producer, lyric feedback, melody tips, listening feedback and the final check; `gemini-3-pro-image` for the app's illustrations and icons
- qrcode by Ryan Day (MIT) for share codes
- Salamander Grand Piano samples by Alexander Holm (CC BY 3.0)
- tonejs-instruments samples by Nicholaus Brosowsky (CC BY 3.0)
- Tone.js drum samples
- Baloo 2 and Nunito fonts (Google Fonts)
- Python (NumPy, Pillow, SciPy) for processing the generated art, scripts in `tools/`
- Vercel (hosting and the Gemini serverless function)
- Claude Code (AI coding assistant)
